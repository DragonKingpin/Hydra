# 编码规范
本标准对 Vue 都生效，以下是核心规范：

1. i18n：所有标题、描述、分类均使用i18n，严禁出现“中文(英文)”的括号备注形式。i18n 默认支持 zh_CN、en_US、es-ES。
2. 独立界面架构：摒弃传统的“面包屑导航”和“弹窗对话框”。采用全屏分块式布局或侧边栏联动式单页应用结构。
3. 每个技能模块都是一个独立的视觉区域，点击后通过平滑滚动或视图切换直接展示详情，而非弹出窗口对话框。
4. 严禁把长 JS、CSS 全写在一个文件里面，请进行合理文件拆分。（不要混在一坨，历史屎山代码不要学坏了）
5. 当一个页面可以拆分成子页面模块时，必须拆分成若干个 "崽崽" 页面，不要混一坨。
6. 单个 Vue 文件非必要时，原则上严禁超过 1000 行，如果必要需说明和备案。
7. 页面风格统一直角（矩形风格，别搞的不伦不类、矩形被老鼠咬了一样）。
8. 良好软件工程架构底线，职责划分、边界清晰，业务逻辑、页面逻辑、系统逻辑不要混一坨。
9. 不要搞 API Proxy，调试麻烦的发瘟，直通后端。
