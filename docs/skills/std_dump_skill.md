# STD 标准库操作 Dump 指南

目标：从项目现有标准中导出“增量标准摘要”，供后续 AI 连续工作使用。

## 行为规则
- 先读取总入口文档，如 `import_std.md`
- 再读取 `./standard/*` 与已有 `./std/*` 文档
- 只提炼“新增、全局、静态强制”的约束
- 已在 `standard` 或已有 `std` 中明确存在的内容不重复输出
- 优先导出架构约束、异常边界、命名约定、分层职责、统一行为规则
- 不导出业务细节、样例代码细节、一次性决策过程
- 输出要短、稳、可复用，面向 AI 执行而不是面向人类长篇说明

## 输出格式
输出两个区块：
1. `Std Dump`
2. `Delta Notes`

其中：
- `Std Dump` 写可直接沉淀的标准
- `Delta Notes` 写本次相对已有标准新增了什么

## 去重规则
- 若某条规则已被基础标准覆盖，则跳过
- 若只是具体任务中的局部实现，不上升为标准
- 若属于历史遗留兼容，不写成全局强制，除非用户明确升级为新标准

## 风格要求
- 用短句
- 用规则句，不写过程复盘
- 尽量写成“必须 / 不允许 / 优先 / 仅”这类可执行语言
